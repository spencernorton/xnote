<span size="xx-large">XNote</span>

Sticky notes that stay on your desktop. Each note is its own small window; the first line is its title; everything you type is saved as you go. The hints below cover what is not obvious from looking at a note. The full guide is at <u>https://github.com/spencernorton/xnote/blob/main/docs/user-guide.md</u>.

<span size="x-large">Notes</span>

<u>New, close, delete</u>

New note: CTRL-N, the plus on the toolbar, [Right-click] - [New], or run xnote again.
Close (hide) a note: CTRL-W or [Right-click] - [Close]. A hidden note comes back with [Notes] - [Show All] from any note's menu or from the tray menu.
Delete a note for good: SHIFT-DEL or [Right-click] - [Delete]. XNote asks first unless the note is empty.

Without a tray icon, closing the last visible note quits XNote instead of hiding it.

<u>The toolbar</u>

Hover a note and a toolbar fades in at the bottom; move away and it fades out. Out of the box it holds New (the plus) and Color (the dot).
Add or remove buttons: [Right-click the toolbar]
Show or autohide it: [Preferences] - [View]

<u>Colour and font</u>

Click the colour dot on the toolbar: a row of six sticky-note colours; one click recolours that note.
Colours and font for every note: [Preferences] - [Layout]
Font or colour for one note only: [Right-click] - [Edit] - [Layout]
New notes take a random colour from the palette unless you turn that off in [Preferences] - [Layout].

<u>Moving and resizing</u>

Move: hold CTRL and drag with the left mouse button anywhere on the note.
Resize: hold CTRL and drag with the right mouse button, or drag the grip in the bottom-right corner.
The size of a note is remembered. On Wayland an application cannot place its own windows, so the position is not; the XNote Placement extension for GNOME Shell puts notes back where you left them.

<u>Styling and search</u>

CTRL-B bold, CTRL-I italic, CTRL-U underline; select text and right-click for Strikethrough.
CTRL-F opens a search bar in the note; Enter jumps to the next match, Escape closes it.

<u>Read-only</u>

CTRL-J locks every note against accidental edits. While locked, a left-drag moves a note and a double-click unlocks it for editing.

<span size="x-large">Preferences</span>

Open with [Right-click] - [Preferences], from the tray menu, or with the Preferences toolbar button. Six pages:

View – toolbar, autohide, scrollbar, window decorations
Layout – font, colours, random colour for new notes, default note size
Startup – start after login, open a new note on start, a delay for slow tray hosts, and which notes to show
Tray – enable the tray icon; what a left click on it does
Other – read-only notes, confirm deletion, line numbers
Backup – choose Local Only, Google Drive, Dropbox, or a custom folder/remote; sign in with your cloud provider; set up or unlock end-to-end encryption; back up now or enable hourly background sync

<span size="x-large">Tray icon</span>

The tray icon carries New, Show All, Close All, the list of notes, Preferences, Help and Quit. A left click toggles show/hide of all notes (change it under [Preferences] - [Tray]); a middle click opens a new note.

GNOME Shell shows no tray icons on its own: install the AppIndicator and KStatusNotifierItem Support extension (gnome-shell-extension-appindicator on Ubuntu). Without a tray icon, XNote keeps the notes as the only way to reach it: closing the last visible note quits, and XNote will not start with nothing to show.

<span size="x-large">Shortcuts</span>

<tt>F1: Help
CTRL-N: New note
CTRL-W: Close (hide) this note
SHIFT-DEL: Delete this note
F5: Reload this note from disk
CTRL-Q: Quit
CTRL-Z / CTRL-Y: Undo / Redo
CTRL-B / CTRL-I / CTRL-U: Bold / Italic / Underline
CTRL-F: Find in this note
CTRL-J: Read-only on/off for all notes
Menu or SHIFT-F10: The note's right-click menu
CTRL + left drag: Move the note
CTRL + right drag: Resize the note</tt>
